## E2E 场景（按用户故事分组）

### US1 - 工作区总览与快速进入

- [x] E2E-01 打开画布 → 全部工作区以卡片呈现（标题/路径/会话数/最近活跃），数量与侧边栏列表一致；首帧呈现 ≤ 1s
- [x] E2E-02 点击工作区卡片 → 进入该工作区新会话并退出画布
- [x] E2E-03 点侧边栏会话/工作区行或「关闭」→ 画布退出，对话界面恢复且原对话状态保留

### US2 - 布局持久化

- [x] E2E-04 拖拽卡片位置 → 刷新/重开画布 → 位置一致
- [x] E2E-05 写入损坏数据 → 提示 + 空布局启动（不崩溃），原数据备份保留

### US3 - 编排画布平台（节点与连线）

- [ ] E2E-06 第三方注册节点类型 → 节点出现在画布并按注册外观渲染
- [ ] E2E-07 创建无归属节点 → 系统要求先落入工作区（无游离态）
- [ ] E2E-08 同工作区两节点拖线 → 连接建立成功
- [ ] E2E-09 跨工作区两节点拖线 → 默认拒绝并给出原因

### US4 - 工作区管理与可扩展右键操作

- [x] E2E-10 右键工作区 → 菜单含进入/重命名/删除/归档
- [x] E2E-11 删除含成员的工作区 → 确认（列出成员数）→ 级联清理成员与关系
- [ ] E2E-12 第三方注册扩展动作 → 右键菜单出现并可执行

### US5 - 明细面板

- [x] E2E-13 点击工作区 → 右侧明细（基础信息 + 会话数，不含条目列表；有跳转侧边栏会话列表入口）
- [ ] E2E-14 点击注册类型节点 → 明细含内置视图 + 扩展区块（按序）
- [x] E2E-15 点空白/关闭 → 面板收起

### US6 - 面板互斥

- [ ] E2E-16 画布打开时打开 dsh-hello 测试面板 → 画布让位
- [ ] E2E-17 dsh-hello 测试面板打开时打开画布 → 面板让位

### US7 - 设置项

- [ ] E2E-18 关闭画布开关 → 入口/内容/公告均消失；若画布正打开则立即关闭；其他功能不受影响
- [ ] E2E-19 重新开启 → 恢复且布局保留

### US8 - 视图浏览（本轮激活）

- [x] E2E-20 缩放 0.3x–3x、平移流畅；新节点自动落位不重叠；拖拽有对齐参考
  - 已实现：缩放（滚轮/工具栏 0.3–3x）、空白平移、视图重置与持久化（本轮 T038–T041，playwright 真机已验证）。
  - 后续增量：GRID 自动布局、拖拽对齐辅助线。

### 边界情况

- [ ] E2E-21 工作区从官方列表消失 → 提示 + 清理其成员与关系
- [ ] E2E-22 无工作区/首次打开 → 空状态引导，不报错
- [ ] E2E-23 节点插件卸载 → 占位显示，位置与关系保留，重装恢复
- [ ] E2E-24 拖节点出所有工作区区域 → 无效提示，节点保持原位
- [ ] E2E-25 画布与其他面板并发打开 → 后打开者胜，不双占
