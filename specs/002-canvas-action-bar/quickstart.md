## E2E 场景（按用户故事分组）

### US1 - 底部操作栏整合缩放与视图控制

- [x] E2E-01 打开画布 → 底部出现操作栏（缩小/百分比/放大/重置视图），右上角无独立缩放工具
- [x] E2E-02 点放大 → 百分比递增 10% 并夹取上限 300%；点缩小同理下限 30%
- [x] E2E-03 点「重置视图」→ 缩放回 100%、平移原点归位
- [x] E2E-04 拖拽卡片经过操作栏附近 → 操作栏不拦截，卡片正常落位
- [x] E2E-05 操作栏样式与系统一致：无硬编码颜色（静态检查不引入非 `--dsw-alias-*` 视觉值）

### US2 - 自动布局

- [x] E2E-06 手动拖成重叠/错位 → 点「自动布局」→ 全部卡片按网格不重叠排布、对齐网格线
- [x] E2E-07 含成员的工作区执行自动布局 → 成员随工作区移动、相对位置保留
- [x] E2E-08 自动布局后刷新页面重开画布 → 布局结果保留
- [x] E2E-09 无工作区时自动布局按钮禁用/空操作，不报错

### US3 - 聚焦工作区

- [x] E2E-10 平移到目标不可见 → 聚焦某工作区 → 画布平移使目标卡片居中可见
- [x] E2E-11 聚焦只平移不改缩放（zoom 保持）
- [x] E2E-12 目标缺失（feed 中消失）→ 提示且视图不变

### 边界情况

- [x] E2E-13 重置视图时已是 100%/原点 → 幂等，无多余写入
- [x] E2E-14 操作栏与右键菜单/明细面板同时出现 → 弹出层不被操作栏遮挡
- [x] E2E-15 全程零控制台错误
