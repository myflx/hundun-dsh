## User Scenarios & Testing *(mandatory)*

### User Story 1 - 底部操作栏整合缩放与视图控制（Priority: P1）

画布打开时，底部显示一条操作栏：缩放（缩小 / 百分比 / 放大）、重置视图。右上角原有的独立缩放工具整合进该操作栏（不再重复出现）。操作栏视觉与系统界面一致（同款背景、边框、圆角、悬停态），不遮挡画布内容。

**Why this priority**: 缩放是画布高频操作，当前位于右上角浮层，视觉突兀且与系统控件风格不统一；整合到底部操作栏后形成统一的画布控制入口，是其余操作按钮（自动布局/聚焦）的载体。

**Independent Test**: 打开画布 → 底部出现操作栏（含缩小/百分比/放大/重置视图）→ 右上角无独立缩放工具 → 点放大百分比递增、点重置回到 100% 与原点 → 操作栏样式使用系统设计令牌（与侧边栏/设置面板同源）。

**Acceptance Scenarios**:

1. **Given** 画布已打开, **When** 用户查看底部, **Then** 操作栏显示缩放控件（缩小/百分比/放大）与「重置视图」按钮，右上角不再有独立缩放工具
2. **Given** 画布已缩放（如 110%）, **When** 用户点「重置视图」, **Then** 视图回到 100% 缩放且原点归位
3. **Given** 操作栏处于画布底部, **When** 用户拖拽卡片至操作栏附近, **Then** 操作栏不拦截拖拽、卡片可正常落位（操作栏为低干扰浮层，不覆盖可交互区域）
4. **Given** 画布打开, **When** 用户检查操作栏外观, **Then** 其背景/边框/圆角/悬停态与系统其他面板一致（复用系统设计令牌，无硬编码颜色）

---

### User Story 2 - 自动布局（Priority: P2）

操作栏提供「自动布局」按钮：一键按网格重新排布全部工作区卡片，消除重叠、对齐网格；成员节点跟随其所属工作区移动，相对位置保留。

**Why this priority**: 拖拽多了布局易乱（重叠/错位），自动布局恢复整齐排布，是画布管理的高价值操作；独立于缩放整合可单独交付。

**Independent Test**: 手动把多张卡片拖成重叠/错位 → 点「自动布局」→ 全部卡片按网格不重叠排布，成员相对位置不变。

**Acceptance Scenarios**:

1. **Given** 画布中有重叠/错位的工作区卡片, **When** 用户点「自动布局」, **Then** 全部卡片按网格重新排布、互不重叠、对齐网格线
2. **Given** 某工作区含成员节点, **When** 执行自动布局, **Then** 成员随工作区移动且相对位置保留
3. **Given** 自动布局已执行, **When** 刷新页面重开画布, **Then** 布局结果持久化保留

---

### User Story 3 - 聚焦工作区（Priority: P3）

操作栏提供「聚焦」能力：选择某个工作区后，画布平移使该工作区卡片居中（缩放保持不变），方便在大画布中快速定位目标。

**Why this priority**: 工作区多时在画布中寻找目标成本高；聚焦平移是低成本高感知的导航增强，优先级低于核心缩放整合与自动布局。

**Independent Test**: 把画布平移到远处 → 从聚焦菜单选择某工作区 → 画布平移使该卡片居中可见。

**Acceptance Scenarios**:

1. **Given** 画布已平移/缩放到目标不可见, **When** 用户选择聚焦某工作区, **Then** 画布平移使该工作区卡片进入可视区域（居中）
2. **Given** 聚焦目标在工作区列表中不存在（已消失）, **When** 用户尝试聚焦, **Then** 给出提示且画布位置不变
3. **Given** 画布只有一个工作区, **When** 用户聚焦它, **Then** 视图稳定不跳动

---

### Edge Cases

- 画布极窄（操作栏空间不足）：缩放控件收缩为「− 百分比 +」紧凑排布，不换行溢出
- 自动布局时工作区数量为 0：操作按钮禁用或空操作，不报错
- 聚焦目标在布局/对账中消失：提示「工作区不存在」，视图保持原位
- 操作栏与右键菜单/明细面板同时出现：操作栏层级低于弹出层，弹出层不被遮挡
- 重置视图时无任何平移/缩放（已是 100%/原点）：幂等，不产生多余动画或写入

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在画布打开时于底部显示操作栏，包含缩放控件（缩小 / 百分比 / 放大）与「重置视图」按钮
- **FR-002**: 系统 MUST 移除右上角原有的独立缩放工具（整合后不重复出现）
- **FR-003**: 缩放控件 MUST 实时反映当前缩放百分比；点放大/缩小以固定步进（10%）变化，夹取在 30%–300%
- **FR-004**: 「重置视图」MUST 将缩放恢复至 100% 并将平移原点归位
- **FR-005**: 操作栏 MUST 复用系统设计令牌（背景/边框/圆角/悬停态/文字色），与系统其他界面控件视觉一致
- **FR-006**: 操作栏 MUST 为低干扰浮层：不拦截画布节点拖拽与空白平移交互，不遮挡可操作区域
- **FR-007**: 系统 MUST 提供「自动布局」操作：按网格重新排布全部工作区卡片，消除重叠并保留成员相对位置
- **FR-008**: 自动布局结果 MUST 随画布文档持久化（刷新后保留）
- **FR-009**: 系统 MUST 提供「聚焦工作区」操作：选择目标后平移画布使其居中可见；目标缺失时提示且视图不变
- **FR-010**: 操作栏按钮在对应操作不可用（如无工作区）时 MUST 安全降级（禁用或空操作），不产生错误

### Key Entities *(include if feature involves data)*

- **CanvasDocument.view**: 视图变换（平移 x/y + 缩放 zoom），操作栏缩放/重置/聚焦读写该状态，随文档持久化
- **CanvasDocument.nodes（workspace 节点）**: 工作区位置（scene 坐标），自动布局重写其 position 字段
- **WorkspaceListState.items**: 工作区列表（聚焦目标与自动布局的对象来源，官方 feed 实时数据）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户打开画布后能在 1 秒内定位到操作栏并完成一次缩放或重置操作
- **SC-002**: 自动布局后工作区卡片零重叠（全部卡片包围盒两两不相交），并落在网格线上
- **SC-003**: 聚焦操作后目标工作区卡片完整进入可视区域（无横向/纵向裁剪）的比例为 100%
- **SC-004**: 操作栏视觉与系统控件一致：不引入任何非系统设计令牌的硬编码颜色/圆角/阴影（静态检查通过）
- **SC-005**: 以上操作全程零控制台错误；刷新后自动布局与视图状态保留

## Assumptions

- 「参考 hundun-web 的功能点」指其画布操作类能力：重置视图（resetView）、聚焦工作区（focusWorkspace）、自动布局（GRID 排布）；对齐辅助线、碰撞推挤、拖拽创建为拖拽行为而非操作按钮，不在本规格范围（已有 P2 增量设计）
- 缩放步进固定为 10%，范围沿用现有 30%–300% 夹取（与当前实现一致）
- 「UI 与系统一致」指复用 dsh 系统设计令牌（`--dsw-alias-*` CSS 变量）与现有控件样式范式（如侧边栏按钮/设置面板卡片），不引入新设计语言
- 操作栏为画布内浮层（absolute 定位），不占用官方槽位，遵循既有面板互斥协议
- 聚焦工作区的目标来源为官方工作区 feed；聚焦仅平移、不改变缩放（保持用户当前缩放级别）
- 自动布局对所有工作区节点重排（覆盖已存位置），是显式用户操作而非自动触发
- 依赖既有能力：视图变换（view-transform）、文档持久化（CanvasDocument.view / workspace 节点 position）、画布挂载（CanvasController）
