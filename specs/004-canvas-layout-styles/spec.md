## User Scenarios & Testing *(mandatory)*

> **澄清（2026-08-17）**：用户明确「我需要的是背景画布风格切换，而非具体的功能改变」——
> 本特征范围 = **画布背景视觉风格**（网格底 / 点阵 / 纯色 / 渐变等），
> 卡片排列、拖拽、缩放、详情框等既有功能一律不变。默认风格 = 现状网格底；
> 快捷切换入口 = 画布底部操作栏。

### User Story 1 - 在设置中选择画布背景风格 (Priority: P1)

用户打开 DSH 设置页的「画布」栏目，看到重新设计后的分组布局：第一组「启用」保留画布开关，
第二组「画布背景风格」提供多种背景风格供选择（名称 + 一句说明）。选中任一风格后立即生效，
打开画布即按新背景渲染；选择持久化，刷新后保持。

**Why this priority**: 「配置项增加多种风格的画布的切换」是本特征核心——设置入口先行，
背景风格才有落点。

**Independent Test**: 在设置页切换背景风格 → 打开画布背景为新风格；刷新页面 → 保持。

**Acceptance Scenarios**:

1. **Given** 设置页画布栏目，**When** 用户选择「点阵」背景，**Then** 打开画布后
   背景为点阵（非网格），卡片/拖拽/缩放/详情行为不变
2. **Given** 设置页选择过「纯色」，**When** 刷新页面并再次打开画布，**Then** 仍为纯色背景

---

### User Story 2 - 画布内快捷切换背景风格 (Priority: P2)

画布打开状态下，用户在**底部操作栏**（缩小/重置/放大/刷新旁）通过背景风格控件切换：
当前风格高亮；切换即时生效且持久化，设置页同步显示。

**Why this priority**: 快捷切换让用户在真实画布上对比各背景，直观且操作 ≤2 次。

**Independent Test**: 画布操作栏切换背景风格 → 画布背景立即变化，设置页对应选项选中。

**Acceptance Scenarios**:

1. **Given** 画布打开（背景为网格），**When** 用户在操作栏切换到「渐变」，**Then**
   背景立即变为渐变，且设置页对应选项被选中
2. **Given** 画布打开，**When** 用户浏览背景风格控件，**Then** 每种风格有名称与
   一句说明，当前风格有选中态

---

### User Story 3 - 各背景风格渲染正确且功能不变 (Priority: P1)

每种背景风格有可感知的视觉差异，数据与交互完全一致（**最终集合 = 用户选定后修订为 5 种**）：

- **网格**（默认，现状）：无限网格底，随平移取模跟随，缩放仅作用节点层
- **点阵**：圆点矩阵底，随平移取模跟随
- **纯色**：无图案纯背景（跟随系统背景令牌）
- **渐变**：柔和渐变背景
- **暗色网格**：深色网格，暗色主题下更隐形的网格底

**Why this priority**: 「支持多种风格」必须落实为可感知的多种背景；全部风格共用同一
工作区数据、选中/详情/打开会话语义与节点层渲染。

**Independent Test**: 对同一组工作区切换所有背景风格：视觉明显不同；任一风格下
单击卡片弹详情、双击进会话、拖拽/缩放/详情宽度调节均与现状一致。

**Acceptance Scenarios**:

1. **Given** 画布有工作区，**When** 用户依次切换全部背景风格，**Then** 背景明显不同，
   且工作区卡片/节点/详情渲染不受影响
2. **Given** 任一背景风格下，**When** 用户单击/双击/拖拽卡片、调整详情宽度，
   **Then** 行为与现状完全一致

---

### Edge Cases

- 背景风格数据损坏/未知值（localStorage 手改）→ 回退默认「网格」，不崩
- 切换背景时正在拖拽/缩放 → 背景层独立于节点层，切换无副作用、状态不丢
- 设置页与画布内切换并发 → 以最后操作为准，两处同步
- 纯色/渐变风格在缩放平移时 → 背景固定不跟随（或按风格定义），节点层始终跟随
- 无工作区空态提示在任意背景风格下可读
- 背景风格注册为空（未来扩展）→ 仅渲染默认「网格」，设置页只显示可用风格

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 支持 5 种背景画布风格：网格（默认，现状）/ 点阵 / 纯色 / 渐变 /
  暗色网格，每种有名称与一句说明（用户选定集合）
- **FR-002**: 设置页「画布」栏目 MUST 重新设计为分组布局：第一组「启用」（画布开关），
  第二组「画布背景风格」（风格单选）；组间有明显分隔
- **FR-003**: 背景风格选择 MUST 持久化（刷新后保持），写入失败 MUST 不阻断切换
  （降级为仅本次会话生效）
- **FR-004**: 背景风格 MUST 由单一注册机制管理（id / 名称 / 说明 / 背景渲染参数），
  新增风格无需改动设置 UI 主体；未知/损坏值 MUST 回退默认「网格」
- **FR-005**: 画布底部操作栏 MUST 提供背景风格快捷切换控件（当前风格选中态），
  切换即时生效且与设置页数据同步（同一持久化源）
- **FR-006**: 全部背景风格 MUST 共用同一工作区数据源与全部既有交互语义
  （单击选中详情 / 双击进会话 / 右键菜单 / 拖拽定位 / 缩放平移 / 详情宽度调节）
- **FR-007**: 背景层与节点层 MUST 解耦：背景切换不重置拖拽/缩放/选中状态
- **FR-008**: 纯色/渐变等非网格背景 MUST 在缩放平移时不露白（背景固定铺满画布容器）

### Key Entities *(include if feature involves data)*

- **CanvasBackgroundStyle（背景风格）**: 画布背景的呈现方式。属性：`id`（唯一标识）、
  `name`（用户可见名称）、`description`（一句说明）、`background`（背景渲染参数，
  如网格间距/点径/颜色/渐变定义）。注册表按 id 索引；配置持久化存 id。
- **CanvasStyleConfig（风格配置）**: 用户在设置中的选择结果：`backgroundId`（当前背景风格）。
  持久化于本地存储，与现有 enabled 开关同一机制（localStorage + 事件广播）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可在 ≤2 次点击内完成背景风格切换（设置页或画布操作栏任一入口）
- **SC-002**: 背景风格选择在刷新后 100% 保持（持久化成功时）
- **SC-003**: 同一组工作区在任意背景风格下渲染一致（数量、位置、详情可用），
  且 5 种风格肉眼可辨
- **SC-004**: 任意背景风格下，单击/双击/拖拽/缩放/详情宽度调节 100% 可用（与现状一致）
- **SC-005**: 设置页画布栏目视觉上分为 ≥2 个清晰分组（启用 / 背景风格）

## Assumptions

- 「风格」= **画布背景视觉风格**（用户澄清），不含卡片排列方式、不含视觉主题色
- 默认背景风格 = 现状「网格」，向后兼容：未设置过风格的用户行为与现状完全一致
- 背景风格配置持久化沿用现有 localStorage + 事件广播机制（与 enabled-store 同模式），
  不引入新的后端存储
- 背景风格集合 = 用户选定后修订为 5 种：网格 / 点阵 / 纯色 / 渐变 / 暗色网格
  （原候选「蓝图」已按用户要求移除）
- 画布内快捷切换入口 = 底部操作栏（用户已确认）
- 数据源不变：官方 workspaces feed 与 sessions 运行状态
